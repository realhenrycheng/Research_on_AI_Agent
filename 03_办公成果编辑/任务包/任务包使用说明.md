# 测试三任务包使用说明

## 本轮冻结任务

本轮测试三只冻结 2 个正式任务：

| 测试编号      | 来源编号     | 类型          | 输入文件                            |
| --------- | -------- | ----------- | ------------------------------- |
| OEDIT_001 | SSB2_003 | Excel 表格调试  | `Embedded Hardcodes_input.xlsx` |
| OEDIT_002 | SSB2_005 | Excel 数据可视化 | `Task 1420776_input.xlsx`       |

## 给 agent 的发送方式

每次只发送一题：

1. 先发送 `办公成果编辑正式提示词_v1.0.md`；
2. 再发送对应题目的 `任务说明.md`；
3. 明确平台输出目录，例如 `WorkBuddy输出`；
4. 启动秒表，从发送任务材料并让 agent 开始执行时计时；
5. 当 agent 完成指定两个文件输出时停止计时。

## 输出目录

每题输出到：

```text
F:\GitHub\AI_Agent\03_办公成果编辑\原始输出\{平台输出目录}\{测试编号}
```

平台输出目录只能为：

```text
ChatGPT_Work输出
WorkBuddy输出
TRAE_Work输出
```

## 本轮不要求记录

- 

只记录总耗时、模型/模式、积分或额度、是否人工干预、是否重跑即可。
