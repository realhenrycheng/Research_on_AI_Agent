## OEDIT_001 — Embedded Hardcodes Excel 审计修复

- **任务**：审计并修复 LBO 金融模型中的嵌入硬编码、公式逻辑错误和断引用问题
- **输入**：`SpreadsheetBench2数据/.../Embedded Hardcodes_input.xlsx`（10 个工作表）
- **输出**：`原始输出/WorkBuddy输出/OEDIT_001/OEDIT_001_修订后.xlsx` + `变更说明.md`
- **修复数量**：36 处，涉及 3 个工作表（Model / Financial Overview / Financial Performance）
- **核心问题类型**：
  1. **嵌入硬编码公式**：如 `=F8-62.457`，常数嵌入而非单元格引用 → 修复为 `=C8+D8`
  2. **跨表引用缺失**：E-H 列未遵循 C/D 列已建立的 `'Financial Overview'!{col}{row}` 模式 → 补齐跨表引用
  3. **硬编码值替代公式**：如 E20 直接写 95 而非公式 → 修复为 `=C20+D20`（正确值 94.967）
  4. **AVERAGE 误用**：`=AVERAGE(360,365)` 用于输入值 → 直接写 362.5
- **方法**：openpyxl `data_only=False` 读取公式 → 模式识别推断正确公式 → 批量修改 → 验证脚本全量复核
- **验证结果**：36/36 全部通过，未修改单元格抽查无误，10 个工作表完整保留
