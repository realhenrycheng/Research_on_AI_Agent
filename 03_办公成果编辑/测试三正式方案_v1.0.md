# 测试三办公成果编辑正式方案 v1.0

## 一、本轮目标

本轮测试三评估三家 agent 对本地办公文件的实际编辑能力，重点看是否能读写 Excel、保留结构、完成指定修改并交付可打开文件。

本轮不做大规模题库，只跑 2 个 Excel 任务：

| 测试编号 | 类型 | 目的 |
| --- | --- | --- |
| OEDIT_001 | 表格调试 | 测试公式审计、硬编码修复、模型维护能力 |
| OEDIT_002 | 数据可视化 | 测试数据整合、图表创建、缺失值处理能力 |

## 二、冻结材料

- 正式提示词：`03_办公成果编辑\提示词\办公成果编辑正式提示词_v1.0.md`
- 任务包：`03_办公成果编辑\任务包\办公成果编辑\OEDIT_001`、`OEDIT_002`
- 评分规则：`03_办公成果编辑\评分\办公成果编辑评分规则_v1.0.md`
- 运行记录：`03_办公成果编辑\测试三运行记录.csv`

冻结后，agent 跑题时不得临时更改任务说明或评分规则。若必须修改，应先另存 v1.1，并在决策记录中说明。

## 三、平台与模型记录

三家平台均执行同一套任务：

```text
ChatGPT Work
WorkBuddy
TRAE Work
```

每次运行记录平台名称、模型/模式、总耗时、积分/额度、上下文用量、人工干预、是否重跑。

## 四、正式输出目录

```text
F:\GitHub\AI_Agent\03_办公成果编辑\原始输出\{平台输出目录}\{测试编号}
```

平台输出目录：

```text
ChatGPT_Work输出
WorkBuddy输出
TRAE_Work输出
```

每题必须交付：

```text
{测试编号}_修订后.xlsx
变更说明.md
```

## 五、暂不纳入 DECKBench 的原因

当前 DECKBench 本地只有论文和幻灯片 URL 清单，没有已下载材料实体。若本轮加入，会额外测试下载、网络访问和材料获取能力，偏离本轮“办公文件编辑交付”的核心目标。

DECKBench 可在后续作为测试三补充题单独跑。
