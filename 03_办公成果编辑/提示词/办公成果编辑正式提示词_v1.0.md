# 办公成果编辑正式提示词 v1.0

## 冻结信息

- 适用测试：测试三“办公成果编辑”。
- 版本：v1.0。
- 冻结日期：2026-08-05。
- 适用对象：WorkBuddy、ChatGPT Work、TRAE Work。
- 输出语言：中文；源文件中的英文表名、字段名、图表标签、公式和原始业务文本按实际需要保留英文。

## 总体任务

你将收到一个办公文件编辑任务包。请只根据任务包中的 `任务说明.md` 和指定输入文件完成编辑，并在指定输出目录中交付可打开、可复核的最终文件。

本测试评估的是办公成果编辑能力，不接受只给文字建议、不交付修改后文件的回答。

## 统一规则

1. 不得修改源数据目录中的原始输入文件；必须另存为任务要求的输出文件名。
2. 只修改任务要求涉及的内容，尽量保留原文件结构、表名、样式、公式布局、命名风格和已有格式。
3. 可以使用 Excel、脚本、内置工具或平台自带办公编辑能力完成任务，但最终结果必须是可打开的 `.xlsx` 文件。
4. 不得访问参考答案文件、golden 文件、评分规则中的隐藏答案，或任何同题参考输出。
5. 如果平台无法直接读写本地路径，应明确说明障碍，并尽力在指定输出目录交付可下载/可保存的结果；不得改用临时目录替代正式输出目录。
6. 完成后必须同时交付修改后的 Excel 文件和中文变更说明。

## 标准输出路径

本题输出绝对路径必须使用以下模板：

```text
F:\GitHub\AI_Agent\03_办公成果编辑\原始输出\{平台输出目录}\{测试编号}
```

`{平台输出目录}` 只能填写以下之一：

```text
ChatGPT_Work输出
WorkBuddy输出
TRAE_Work输出
```

`{测试编号}` 必须与任务说明一致，例如：

```text
F:\GitHub\AI_Agent\03_办公成果编辑\原始输出\ChatGPT_Work输出\OEDIT_001
```

## 固定交付文件

每题必须创建以下两个文件：

```text
{测试编号}_修订后.xlsx
变更说明.md
```

`变更说明.md` 必须包含：

```markdown
# 变更说明

## 1. 任务信息

| 项目 | 内容 |
| --- | --- |
| 测试编号 |  |
| 平台 |  |
| 输入文件 |  |
| 输出文件 |  |

## 2. 已完成修改

- ...

## 3. 复核方式

- ...

## 4. 未完成或异常

无
```

如果存在未完成项、权限问题、文件打不开、图表无法生成、公式无法确认等情况，必须在“未完成或异常”中如实说明。

## 禁止事项

- 禁止只输出文字建议而不交付修改后的 `.xlsx`。
- 禁止覆盖原始输入文件。
- 禁止访问或引用 golden/参考答案文件。
- 禁止为了看起来完成而删除复杂工作表、简化模型结构、把公式改成静态值，除非任务明确要求。
- 禁止把缺失数据当作 0 填入图表；如果任务要求保留缺口，应按任务要求处理。

## 完成标准

- 输出文件可以正常打开。
- 任务要求中的核心编辑已完成。
- 原有工作簿结构和格式被尽量保留。
- 变更说明能让人工评审快速知道改了什么、如何复核。
