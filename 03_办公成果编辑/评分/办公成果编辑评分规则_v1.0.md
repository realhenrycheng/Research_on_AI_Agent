# 测试三办公成果编辑评分规则 v1.0

## 一、适用范围与冻结边界

- 适用对象：ChatGPT Work、WorkBuddy、TRAE Work 在测试三办公成果编辑任务中的正式输出。
- 本轮样本：OEDIT_001、OEDIT_002，共 2 题。
- 评分开始条件：三家均完成本轮 2 题、输出文件冻结、运行记录填写完成。
- 评分依据：任务包、三家正式输出、SpreadsheetBench 2 原始输入文件、隐藏参考答案文件、运行记录。
- 参考答案文件只允许评分阶段使用，不得发送给 agent。

## 二、交付门槛

每题必须位于：

```text
F:\GitHub\AI_Agent\03_办公成果编辑\原始输出\{平台输出目录}\{测试编号}
```

并包含：

```text
{测试编号}_修订后.xlsx
变更说明.md
```

若缺少修订后 `.xlsx`，或文件无法打开，该题质量分为 0。若缺少 `变更说明.md`，不归零，但在可复核性维度扣分。

## 三、总分构成

主评分满分 100 分：

| 部分 | 分值 |
| --- | ---: |
| 编辑正确性 | 40 |
| 任务完整性 | 25 |
| 文件可用性与格式保真 | 15 |
| 可复核性 | 10 |
| 效率 | 10 |
| **总分** | **100** |

效率低权重，只反映完成速度，不替代办公编辑质量。

## 四、逐题质量评分

每题质量分满分 45 分，两题合计 90 分。

| 维度 | 单题分值 | 判定方法 |
| --- | ---: | --- |
| 编辑正确性 | 20 | 与任务要求和参考答案对照，检查公式、数据、图表、计算结果是否正确 |
| 任务完整性 | 12.5 | 是否覆盖任务所有明确要求，是否遗漏关键子项 |
| 文件可用性与格式保真 | 7.5 | 输出文件是否可打开，是否保留原结构、格式、工作表、命名风格 |
| 可复核性 | 5 | 是否有清楚的变更说明，是否便于人工定位修改内容 |

## 五、OEDIT_001 评分重点

OEDIT_001 为 Excel 表格调试题。评分时重点检查：

- 是否修复公式逻辑错误和不一致公式；
- 是否识别并处理本应为公式的硬编码数值；
- 是否修复损坏或错误引用；
- 是否避免引入新的计算错误；
- 是否保留原模型结构、工作表名称、格式和主要布局；
- 是否能正常打开并重新计算；
- 变更说明是否列出主要修复类别。

若输出只是文字审计意见而没有实际修复工作簿，该题质量分为 0。

## 六、OEDIT_002 评分重点

OEDIT_002 为 Excel 数据可视化题。评分时重点检查：

- 是否创建多系列折线图；
- 是否包含且只包含 `Systolic`、`Diastolic`、`Pulse`、`Sugar` 四个核心系列；
- 日期范围是否覆盖 2024-02-08 至 2024-03-08；
- 是否正确合并 2024 年 2 月和 3 月数据；
- X 轴是否清晰显示日期、星期、时间；
- X 轴标签是否可读，不明显重叠；
- 缺失数据是否显示为线条缺口，而不是 0 或插值；
- Y 轴比例是否能清楚展示四个系列，建议 0 至 250；
- 图表是否在 Excel 中正常显示。

若没有创建图表，或图表无法在输出文件中打开查看，编辑正确性最高不超过 8/20。

## 七、效率评分

三家均完成 2 题后，使用 `测试三运行记录.csv` 中的总耗时计算效率。

```text
效率得分 = 10 × sqrt(三家中最短总耗时 ÷ 本平台总耗时)
```

- 总耗时为两题耗时之和，单位统一为秒。
- 最快平台效率分为 10。
- 若某题重跑，使用用户指定的正式轮次；未指定时使用第一次完整交付且未废弃的轮次。

## 八、成本与资源分析

积分或额度消耗不进入主评分，但必须记录并分析：

| 指标 | 说明 |
| --- | --- |
| 总积分/额度 | 两题消耗合计 |
| 平均积分/额度 | 总消耗 ÷ 有记录题数 |
| 积分/额度变异 | 判断消耗是否稳定 |
| 时间-积分关系 | 观察耗时长是否通常更耗额度 |
| 质量-积分关系 | 观察高消耗是否对应更高质量 |

不得仅凭积分波动断定平台切换模型。若平台没有同口径积分记录，标记为“未记录/不可比”。

## 九、异常与人工干预

- 平台无法打开或写入本地文件：记录为权限/环境异常，不自动扣质量分；若因此未交付 `.xlsx`，按交付门槛处理。
- 人工提醒路径、重发提示词、手动上传文件：计入人工干预次数。
- 人工直接修改输出文件：该轮不得作为纯 agent 结果，需重跑或单独标注。
- 文件损坏、打不开、扩展名伪装：该题质量分为 0。

## 十、扣分记录格式

评分明细至少包含：

```text
平台,测试编号,评分维度,满分,得分,扣分,扣分原因,使用文件,复核备注
```

所有扣分必须有具体原因，不能只写“效果一般”。
