# Research on AI Agent

**AI Agent 能否重塑行业研究工作流?——以 WorkBuddy 为例的实证研究**

券商研究所面试课题(东方证券研究所 · WorkBuddy 专题研究),2026 年 8 月。

## 研究问题

不比较"谁分数高",而是回答:WorkBuddy 能否进入真实研究流程?在哪些环节创造价值、哪些环节制造摩擦?腾讯生态是放大还是缩小这种价值?

## 研究方法

四项实验,全部基于冻结任务包与统一输入的真实运行:

| 实验 | 考察内容 | 竞品参照 |
|---|---|---|
| 测试一 专题研究 | 从公开资料形成研究交付 | ChatGPT Work / TRAE Work |
| 测试二 事实核验 | 证据落回、材料不支持时停止 | 同上 |
| 测试三 办公编辑 | 真实修改 Excel 并交付 | 同上 |
| 04 腾讯生态 | 三层证据链(L1 模拟 / L2 真实闭环 / L3 摩擦对比) | 人工基线 |

## 核心结论

1. WorkBuddy 平台上限不低(办公编辑 92.10 居首、强模型下研究 91.25 逼近第一梯队),但表现高度依赖模型配置;
2. 事实核验仍需人工复核,积分成本波动大(变异系数约 67%)且与质量不相关;
3. 生态价值按环节分化:知识库/文档读写为正,PPT+邮件分发为负(60 分钟 0 交付 vs 人工 10-20 分钟);
4. 定位判断:现阶段是"带人工复核的研究与办公助手",不是无人值守的办公替身。
