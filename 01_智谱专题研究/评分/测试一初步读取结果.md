## 三、初步观察

### WorkBuddy

优点：覆盖模型版本最多，时间线从 GLM 架构延伸到 GLM-5.2，并单列 GLM-4.6、GLM-4.7、AutoGLM 等节点；核心结论明确引用事实编号，PPT 大纲页数完整。

风险：大量使用 2025/2026 最新版本、媒体报道和第三方模型卡，后续需要重点核验发布时间、参数、上下文长度、榜单排名和 API 价格。它的优势是“信息多”，但也意味着复核成本高。

### ChatGPT Work

优点：结构稳定，来源偏官方文档、论文、GitHub 和模型卡；对“官方评测不能直接等同市场排名”有谨慎提示；备忘录章节完整，比较适合做报告正文底稿。

风险：覆盖面略少于 WorkBuddy，对部分版本采用保守处理；如果目标是展示最新智谱动态，需要补充后续版本和商业化信息。

### TRAE Work

优点：运行速度最快，事实核验清单数量最多；对早期 ChatGLM 系列、GLM-4、GLM-4.5V 的技术来源引用较集中。

风险：备忘录和 PPT 大纲更短，交付物密度低于另外两家；后续需要检查它是否遗漏 GLM-4.6、GLM-4.7、GLM-5/5.2 等最新节点，或者只把它们放在风险提示中。

## 四、下一步复核重点

建议先不直接打总分，先做事实抽检。优先核验以下类别：

1. 发布时间：GLM-130B、ChatGLM-6B、GLM-4、GLM-4.5、GLM-4.6、GLM-4.7、GLM-5.2。
2. 参数口径：GLM-4 是否未披露；GLM-4.5 是否为 355B/32B；GLM-4.5V 是否为 106B/12B；GLM-5 是否存在 744B/40B 口径。
3. 上下文长度：GLM-4 128K、GLM-4.7 200K、GLM-5.2 1M 等是否有官方来源。
4. 开源状态：哪些是权重开源，哪些只是 API 或网页产品开放。
5. 榜单与排名：全球第二/第三、开源 SOTA、国产第一等表述是否来自官方自评还是第三方榜单。
6. 价格与套餐：凡涉及免费、元/百万 tokens、美元价格的内容，都要按测试日期重新查官方价格页。

## 五、暂定结论

从“交付完整性”看，三家均合格。若只看速度，TRAE Work 最优；若看覆盖范围，WorkBuddy 最强；若看复核友好度和谨慎程度，ChatGPT Work 当前更稳。

正式评分前需要进入事实核验阶段，不能仅凭文本观感确定排名。
