# WorkBuddy 换模型评估报告

## 1. 结论摘要

本次对照的是 WorkBuddy 在同一提示词和同一任务下的三种配置：主测试 HY3、Auto + MAX、DeepSeek V4 Flash API + MAX。两次换模型复测均启用 MAX 模式；三者均完整生成五份要求文件，因此均通过交付门槛。

| 配置 | 综合得分 | 主要优势 | 主要风险 |
| --- | ---: | --- | --- |
| Auto + MAX | 91.25 | 事实清单、风险提示和来源结构最均衡；用时较 HY3 减少 48.6% | 仍有若干媒体转述和逐版许可证合并判断 |
| DeepSeek V4 Flash | 90.00 | 速度最快；覆盖面和结构化程度很高 | 第三方汇总、媒体转述和强商业化断言较多，需压低确定性措辞 |
| HY3 基线 | 83.73 | 核心家族覆盖完整 | 来源更依赖媒体/聚合站，且用时最长 |

本次最值得保留的工作结论是：WorkBuddy 对底层模型配置依赖较强。在相同任务和 MAX 模式下，Auto 与 DeepSeek V4 Flash 都显著优于 HY3，但优势方向不同：Auto 在本次事实、观点和来源审计中得分最高；DeepSeek V4 Flash 速度最快，且仅使用 14.22% 的 1M 上下文窗口，表现出更大的长任务余量。上下文余量不是单独的质量分，却是复杂、多轮或材料更长任务中值得优先考虑的运行弹性指标。

## 3. 逐维度审计

### 3.1 事实可靠性

抽检表覆盖七类事实，各配置 30 条。Auto 得 93.33，显著高于 HY3 的 86.67；它对发布日期冲突、参数未披露、榜单时点和价格口径的标注更克制。DeepSeek V4 Flash 得 86.67，与 HY3 持平：其核心技术时间线多数正确，但“30万企业客户、日调用400亿 tokens”“全程昇腾且无 NVIDIA”等内容没有给出同等级一手证据，不能按确定事实使用。

### 3.2 研究完整性

三种配置均覆盖 12 个核心模型家族。HY3 和 Auto 的字段覆盖均为 115/120，得 98.33；DeepSeek V4 Flash 为 116/120，得 98.67。该维度反映信息组织覆盖，不替代事实可靠性，因此 DeepSeek 的高完整度并不抵消其来源风险。

### 3.3 分析观点

Auto 得 87.50：其“事实/推断/资料不足”分层清晰，策略判断和跟踪框架可以直接用于后续人工复核。DeepSeek V4 Flash 得 82.50：有完整的事实、推断和不足区分，也提供了跟踪表，但“与海外模型差距”“资本化领先”“全栈自研”等判断在证据链不足处略显确定。HY3 得 77.50，主要扣分在策略段落较概括、后续验证口径较弱。

### 3.4 来源与引用

Auto 得 83.00，DeepSeek V4 Flash 得 79.00，HY3 得 70.25。Auto 的关键技术节点更多指向官网、技术报告、模型卡或官方文档；DeepSeek V4 Flash 的技术来源并非全部较弱，但较多使用百科、媒体盘点、聚合模型卡和第三方评测。两者都应把“官方自报”与独立第三方结论分开写，尤其是榜单排名、性能领先和商业化数据。

### 3.5 效率

本组以 DeepSeek V4 Flash 的 290.40 秒为最快基准。DeepSeek V4 Flash 得 100.00，Auto 得 79.50，HY3 得 57.01。Auto 在质量改善的同时把 HY3 的耗时从 893.74 秒缩短到 459.48 秒；DeepSeek V4 Flash 则把时间进一步缩短到 290.40 秒。

## 4. 使用建议

1. 需要在当前提示词下直接形成可复核的研究初稿时，Auto + MAX 是更稳妥的选择：它在本次质量审计中综合得分最高。
2. 需要处理更长材料、预留多轮修改空间或优先追求速度时，DeepSeek V4 Flash API + MAX 更有吸引力：它的上下文窗口余量更大、总耗时最短；成稿前仍须人工复核商业化数字、榜单名次、参数规格和“国产算力训练”类结论。
3. 无论采用哪种配置，最终报告应优先回链到智谱官网、z.ai 技术博客、官方文档、论文和模型卡；媒体与聚合站只作为辅助线索。

## 5. 与主测试的关系

本报告不修改测试一中 ChatGPT Work、WorkBuddy HY3、TRAE Work 的三平台比较结果。HY3 仍保留为主测试中的 WorkBuddy 原始基线；Auto + MAX 和 DeepSeek V4 Flash API + MAX 是 WorkBuddy 的配置复测，用于说明平台内的模型选择会影响结果。
