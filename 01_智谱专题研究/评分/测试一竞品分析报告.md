# 测试一竞品分析报告：智谱专题研究

## 一、分析范围

本报告基于测试一已经完成的三家 agent 主测试结果，以及 WorkBuddy 后续换模型复测结果。主测试对象为 ChatGPT Work、WorkBuddy、TRAE Work；复测对象为 WorkBuddy 的 Auto + MAX 与 DeepSeek V4 Flash API + MAX 配置。

本报告只比较本轮测试中的可观察产出，不把单次结果直接外推为平台全部能力。

## 二、核心量化结论

| 排名 | 平台 | 主测试质量总分 | 总耗时 | 效率分 | 事实可靠性 | 研究完整性 | 分析观点 | 来源与引用 |
|---:|---|---:|---:|---:|---:|---:|---:|---:|
| 1 | ChatGPT Work | 92.81 | 449.03 秒 | 79.73 | 95.00 | 92.82 | 95.00 | 94.92 |
| 2 | TRAE Work | 88.64 | 285.44 秒 | 100.00 | 93.33 | 81.89 | 82.50 | 95.75 |
| 3 | WorkBuddy（HY3） | 83.68 | 893.74 秒 | 56.51 | 86.67 | 98.33 | 77.50 | 70.25 |

从主测试看，ChatGPT Work 的质量总分最高，比 TRAE Work 高 4.17 分，比 WorkBuddy HY3 高 9.13 分。TRAE Work 是速度最优平台，用时仅 285.44 秒；ChatGPT Work 用时约为 TRAE 的 1.57 倍，WorkBuddy HY3 用时约为 TRAE 的 3.13 倍。

维度差异比总分更有解释力。ChatGPT Work 在事实可靠性、研究完整性、分析观点、来源与引用四个维度都处在高位，没有明显短板。TRAE Work 的来源与引用最高，效率也最高，但研究完整性比 ChatGPT Work 低 10.93 分，比 WorkBuddy HY3 低 16.44 分。WorkBuddy HY3 的研究完整性最高，但来源与引用只有 70.25 分，明显低于 ChatGPT Work 和 TRAE Work。

## 三、定性差异

### ChatGPT Work

ChatGPT Work 的优势是综合稳定性。它既能覆盖主要模型谱系，也能把事实、时间线、产品定位和商业化含义组织成比较完整的研究报告。它的分析观点分最高，说明产出不只是堆材料，而是能形成判断链条。

主要不足是速度并非第一，且在极限覆盖面上不如 WorkBuddy HY3。若任务目标是“最快获得材料”，它不是最高效率选项；但若目标是“直接进入人工复核和报告写作”，它的返工压力最低。

### TRAE Work

TRAE Work 的优势是速度快、来源与引用表现好。它适合做快速调研、初步检索和材料补充，尤其适合在时间很紧时先产出一个可读版本。

主要不足是研究完整性和分析观点偏弱。本次产出对部分模型迭代和产品细节覆盖不够充分，分析层也更像整理型摘要，而不是完整的产业研究判断。

### WorkBuddy

WorkBuddy HY3 基线版展现出很强的覆盖倾向，研究完整性最高，说明它愿意展开较宽的材料面。但它的来源结构问题也最明显，抽样检查中一手来源比例偏低，较多依赖媒体报道、聚合页和第三方模型卡。这会导致参数、发布日期、定价、排名等信息需要更高强度的人工复核。

后续换模型复测改变了对 WorkBuddy 的判断。Auto + MAX 得分 91.25，接近 ChatGPT Work 的 92.81；DeepSeek V4 Flash API + MAX 得分 90.00，且用时仅 290.40 秒，接近 TRAE Work 的速度水平。DeepSeek 配置还只使用约 142.2k/1000k 上下文，任务余量明显大于 Auto 配置的 150.5k/168.0k。

因此，WorkBuddy 的关键竞品特征不是“固定低分”，而是“能力高度依赖底层模型和配置”。HY3 免费版下，它像一个覆盖广但需要重审的资料收集器；切换到更强模型和 MAX 模式后，它可以接近第一梯队。

## 四、竞品定位

| 平台 | 适合场景 | 主要优势 | 主要风险 |
|---|---|---|---|
| ChatGPT Work | 高质量研究初稿、最终报告前置草案 | 综合质量最高，事实、引用、分析较均衡 | 速度不是第一 |
| TRAE Work | 快速调研、资料补充、时间敏感任务 | 速度最快，引用结构好 | 覆盖和分析深度不足 |
| WorkBuddy | 大范围资料搜集、可调模型的深度任务 | 覆盖面强，强模型配置下上限明显提升 | HY3 基线来源质量弱，模型依赖强，人工复核压力较高 |

## 五、可写入最终报告的结论

测试一显示，ChatGPT Work 在研究型任务中最接近“可直接进入报告加工”的产出标准；TRAE Work 更像高效率研究助理，适合快速生成可检索、可引用的材料；WorkBuddy 的表现最受模型配置影响，HY3 基线下短板明显，但 Auto + MAX 和 DeepSeek V4 Flash + MAX 复测显示其平台上限并不低。

对中国企业用户来说，这一发现很重要：采购或试用 WorkBuddy 时不能只看平台入口，而必须明确底层模型、上下文容量、MAX 模式、积分消耗和默认路由策略。否则同一平台可能表现出完全不同的质量和成本结构。
