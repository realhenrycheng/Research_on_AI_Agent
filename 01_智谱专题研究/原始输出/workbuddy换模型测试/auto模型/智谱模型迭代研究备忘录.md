# 智谱模型迭代研究备忘录

## 3.1 核心结论

1. **迭代路径清晰且持续加速**：GLM 架构（2021）→ GLM-130B（2022）→ ChatGLM-6B 开源引爆（2023-03）→ GLM-4（2024-01，128K+All Tools）→ GLM-4.5（2025-07，ARC 原生融合）→ GLM-4.7（2025-12，200K+编码 SOTA）→ GLM-5（2026-02，744B/40B MoE+Agentic Engineering）→ GLM-5.2（2026-06，1M+长程任务）。（见 F01–F17）
2. **开源与闭源双轨分工**：ChatGLM 系列及 GLM-4-9B/4.5/4.5V/4.6/4.7/5/5.2 均权重开源（MIT），GLM-4、GLM-4-Plus 闭源走 API/产品，形成「开源引流+闭源变现」互补。（F38–F41）
3. **能力重心明确转向 Agent 与 Coding**：GLM-4.5 首次原生融合 ARC，GLM-4.7 引入三种思考模式，GLM-5 提出 Agentic Engineering，GLM-5.2 主攻长程任务，Agent 能力从「能调用」走向「长程自主执行」。（F59–F63）
4. **上下文长度阶梯跃升**：128K（GLM-4）→ 200K（GLM-4.6/4.7/5）→ 1M 无损（GLM-5.2），直接服务长文档、整库代码与长程自主任务。（F26, F29–F32）
5. **参数规模从稠密走向 MoE**：GLM-130B（130B 稠密）→ GLM-4.5（355B/32B MoE）→ GLM-5（744B/40B MoE），以「大总参数+小激活」换参数效率，GLM-5 同时引入 DeepSeek Sparse Attention。（F18, F22, F23）
6. **多模态从「理解」走向「生成+行动」**：GLM-4V 图像理解 → CogView3/CogVideoX 文生图/视频 → GLM-4-Voice 语音 → AutoGLM 端侧操作手机/PC。（F34–F37）
7. **商业化爆发与国产算力是差异化卖点**：2025 年营收 7.24 亿（+131.9%），MaaS ARR 17 亿；GLM-5.2 Day 0 适配 9 家国产芯片；API 涨价 83% 后调用量反增 400%。（F56, F63, F66, F68）

## 3.2 模型迭代时间线

- **2021–2022 基础研究期**：提出 GLM 自回归空白填充架构，训练 GLM-10B；2022-08/09 开源中英双语 130B 稠密模型 GLM-130B，入选斯坦福 HELM 评测，与 GPT-3 davinci 持平。（F01, F02）
- **2023 开源引爆期**：2023-03-14 开源 ChatGLM-6B（6.2B），成为国内现象级开源对话模型；6 月 ChatGLM2-6B 扩至 32K（MMLU +23%、GSM8K +571%）；10 月 ChatGLM3-6B 支持 Function Calling，Agent 能力雏形出现。（F03–F05）
- **2024 闭源主力+多模态扩张期**：2024-01 GLM-4 发布（128K、All Tools、MMLU 81.5≈GPT-4 94%）；6 月开源 GLM-4-9B（10T tokens、MIT、1M 版）与 GLM-4V-9B；7 月 CogVideoX 文生视频；8 月 GLM-4-Plus；10 月 GLM-4-Voice 与 AutoGLM。（F06–F09）
- **2025 Agent 原生期**：2025-04 开源 GLM-4-32B/GLM-Z1 系列（200 tokens/s）并启用 z.ai；7 月 GLM-4.5（MoE 355B/32B）原生融合 ARC；8 月 GLM-4.5V 视觉推理开源；9 月 GLM-4.6（200K、编码对齐 Claude Sonnet 4）；12 月 GLM-4.7（SWE-bench 73.8% 开源 SOTA、三种思考模式）。（F10–F14）
- **2026 长程任务期**：2026-01 GLM-4.7-Flash（30B/3B、MLA、免费）；02 月 GLM-5（744B/40B、Agentic Engineering、Artificial Analysis 全球第四）；04 月 GLM-5.1（长程任务突破）；06 月 GLM-5.2（1M 无损上下文、Code Arena 全球第一、9 家国产芯片适配）。（F15–F17）

## 3.3 能力演进分析

- **文本理解与生成**：从 GLM-130B 基座到 GLM-4 中文比肩 GPT-4（MMLU 81.5≈94%），到 GLM-4.5/4.7/5 在推理与综合基准持续逼近闭源 SOTA，文本能力已非短板。（F42, F44, F50）
- **长上下文**：128K（GLM-4）→ 200K（GLM-4.6）→ 1M（GLM-5.2）的跨越，使整库代码、数百页 PDF、长篇巨著可一轮处理，是 Agent 与长程任务的基础。（F26, F29, F32）
- **多模态**：理解侧（GLM-4V/4.5V）已达开源 SOTA；生成侧（CogView3 文生图、CogVideoX 文生视频）与交互侧（GLM-4-Voice、AutoGLM）齐全，形成「全模态」产品矩阵。（F34–F37）
- **工具/API 与 Agent 化**：GLM-4 的 All Tools → GLM-4.5 原生 Function Call+MCP+混合推理 → GLM-4.7 三种思考模式 → GLM-5 Agentic Engineering+Slime 异步 RL → GLM-5.2 effort level 与 IndexShare，Agent 能力从「能调用」走向「能长程自主执行」。（F59–F63）
- **开源生态**：ChatGLM-6B 累计千万级下载、智谱开源系列超 4000 万下载，入选 HF Top 15；GLM-4.7 开源代码下载超 6000 万；开源是智谱建立开发者心智与生态壁垒的核心抓手。（F40, F41, F65）
- **企业级与商业化**：MaaS 模式（2025 营收 7.24 亿、ARR 17 亿、客户 400 万+），叠加免费模型引流与 Coding Plan 订阅（24.2 万付费开发者），2026-01 港股上市（02513.HK），6 月申请 A 股科创板。（F54–F58, F66, F68）

## 3.4 智谱模型策略判断

**事实（可核验）**：
- 开源模型覆盖 6B→9B→32B→106B→355B→744B 多档，且 GLM-4.5/4.7/5/5.2 旗舰同步开源（MIT）。（F40, F41）
- GLM-4.5 起明确以「Agentic、Reasoning、Coding（ARC）」为统一训练目标，技术报告公开训练与 RL 框架 slime。（F59，arXiv:2508.06471）
- GLM-5 参数扩展至 744B/40B 并集成 DeepSeek Sparse Attention；GLM-5.2 强调国产算力全适配（9 家）与 MIT 免费商用。（F23, F63）
- 2025-01 被列入美国实体清单后，智谱加速国产算力适配，从训练到推理全面转向华为昇腾等国产芯片。（F67）

**推断（需持续验证）**：
- 智谱更重视「Agent 原生 + 长上下文 + 高性价比开源 + 国产算力」四条主线，意在以开源生态对抗闭源巨头、以国产算力规避供应链风险。
- 开源与闭源分工：开源建立开发者生态与口碑（对标 Meta Llama 路线），闭源 API（GLM-4/4-Plus）及企业私有化承接付费，二者流量与收入互补；Coding Plan 订阅是连接开发者的关键变现路径。
- 相对位置：国产开源模型第一梯队，与 DeepSeek、Qwen 并称；在编码/长程任务上正快速逼近 Claude/OpenAI（GLM-5.2 与 Claude Opus 4.8 差距收窄至 1%–4%），但总参数规模仍受 MoE 架构约束。
- **当前资料不足以支持**：①GLM-5.1 的参数、发布时间与能力细节；②GLM-5.2 的 API 单价与训练算力规模；③GLM-4/GLM-4.6/GLM-5.2 的总参数量；④各版本真实训练成本与利润率。上述均列为「未确认信息」。
