# 智谱模型迭代研究备忘录

> 研究日期：2026-08-04｜本文约 1900 字。所有结论均可回溯至《智谱模型迭代数据库》与《关键事实核验清单》中的事实编号（F1–F83）。

## 3.1 核心结论

- 智谱 2019 年由清华 KEG 实验室转化成立，2021 年发布自研 GLM 预训练框架（F1–F2），是国内最早自研基座的大模型企业之一；2026 年已在港交所上市（F80）。
- 迭代节奏极快且公开透明：从 2023 年 ChatGLM-6B（F9）到 2026-06 的 GLM-5.2（F71），平均 3–6 个月一次基座大版本，2026 年上半年更是三个月连发 GLM-5/5.1/5.2 三代（F64/F67/F71）。
- 架构主线清晰：GLM-130B 稠密（F6）→ ChatGLM 系列 Decoder-Only（F4）→ GLM-4 闭源稠密旗舰（F19）→ GLM-4.5 起全面转向 MoE + 混合推理（F42），最新 GLM-5.2 采用 IndexShare 稀疏注意力实现 1M 无损上下文（F72/F77）。
- 能力重心从「对话」转向「做事」：GLM-4 的 All Tools（F24）→ ChatGLM3 的 Function Calling（F17）→ GLM-4.5 原生融合推理/编码/智能体 ARC 三能力（F43）→ GLM-5.2 专攻长程任务与 Coding（F71–F77），Agent 化是贯穿主线。
- 开源是核心战略：主流旗舰（4.5/4.6/4.7/5/5.1/5.2）全部 MIT 权重开源（F47/F63/F78），并配套国产算力 Day 0 适配（F79）；闭源主力（GLM-4、GLM-4-Plus）仅走 API。
- 国产算力绑定加深：GLM-4.6 首次在寒武纪芯片部署 FP8+Int4（F54），GLM-5/5.1 宣称全程华为昇腾训练、无 NVIDIA（F70），是国产大模型「开源国模+国产算力」组合的代表。
- 商业化双轮驱动：B 端 MaaS 日调用量超 400 亿 tokens、30 万企业客户（F81），C 端清言用户超 2500 万（F82）；API 定价策略激进（GLM-4.5 输入 0.8 元/百万 tokens，F46）。

## 3.2 模型迭代时间线

- **2021–2022 技术奠基**：GLM 框架（2021-03，F2）→ GLM-10B → GLM-130B（2022-09 开源，F5），解决「能否做出千亿级自研基座」问题，并积累斯坦福评测口碑（F7）。
- **2023 开源破圈**：ChatGLM-6B（03-14，F9）以小体积引爆国内开源生态（下载超千万，F11）；ChatGLM2-6B（06-25，F12）上下文 2K→32K（F13）、推理提速 42%（F15）；ChatGLM3-6B（10 月，F16）引入 Function Calling（F17），为 Agent 能力奠基。
- **2024 对标 GPT-4 与全模态**：GLM-4（01-16，F19）128K 上下文、MMLU 81.5、All Tools（F20–F24）；GLM-4-9B（06-05，F25）开源小模型 + 1M 上下文（F28）；GLM-4-Plus 与 VideoCall（08 月，F32–F33）；AutoGLM/GLM-4-Voice（10-25，F34–F35）；GLM-OS 与 GLM-PC（11-29，F36）；GLM-Zero-Preview（12-31，F37）补齐推理。
- **2025 推理与 Agent 爆发**：GLM-Z1-32B 系列开源（04-14，F39，200 tokens/s 比肩 DeepSeek-R1，F40）；GLM-4.5/4.5-Air（07-28，F41）首度原生融合 ARC 三能力（F43）；GLM-4.5V（08-11，F48）视觉推理；GLM-4.6（09-30，F51）200K 上下文、LMArena 第 4（F52–F53）；GLM-4.6V（12-08，F55）原生多模态工具调用；GLM-4.7（12-22，F58）SWE-bench 73.8%、三种思考模式（F61–F62）。
- **2026 长程任务与国产算力**：GLM-5（02-11，F64）744B 级开源旗舰；GLM-5.1（03-27，F67）SWE-Bench Pro 58.4（F69）且全程昇腾训练（F70）；GLM-5.2（06-13/17，F71）1M 上下文、AA 51 分全球开源第一（F72–F74），成为当前主力旗舰。

## 3.3 能力演进分析

- **文本理解与生成**：从 GLM-130B 双语基座（F6）到 GLM-4 的 MMLU 81.5（F22）、GLM-4.5 的 12 基准综合全球第三（F43），再至 GLM-5.2 的 AA 51 分（F74），通用能力持续逼近并部分反超海外闭源模型。
- **长上下文**：2K（ChatGLM-6B，F13）→ 32K（ChatGLM2，F13）→ 128K（GLM-4，F20）→ 1M（GLM-4-9B-Chat-1M，F28）→ 200K 稳态（GLM-4.6/4.7，F52/F60）→ 1M「无损」（GLM-5.2 配 IndexShare，F72/F77），从「能读长文」演进到「长程任务可用」。
- **多模态**：文本 → 图像理解（GLM-4V-9B，F30）→ 视觉推理（GLM-4.5V，F48）→ 原生多模态工具调用（GLM-4.6V，F56）→ 语音（GLM-4-Voice，F35）与视频（VideoCall/清影，F33）的全模态布局；生成侧由 CogView（文生图）、CogVideoX（文生视频）支撑。
- **工具/API 与 Agent 化**：ChatGLM3 Function Calling（F17）→ GLM-4 All Tools/GLMs（F24）→ AutoGLM/GLM-OS/GLM-PC（F34–F36）→ GLM-4.5 混合推理与思考/非思考模式（F41–F43）→ GLM-4.7 三种思考模式（F62）→ GLM-5.2 长程任务（F75–F77），Agent 能力从「API 特性」升格为「模型原生设计」。
- **开源生态**：GLM-130B 打开局面（F5）→ ChatGLM-6B 引爆生态（F9–F11）→ GLM-4-9B MIT 开源（F29）→ GLM-4.5 起旗舰级 MIT 开源（F47/F63/F78），配合 2024 年开源基金「三个 1000」与多平台分发，构建了从研究到商用的完整开源链路。
- **企业级与商业化**：MaaS 平台 30 万企业客户、日调用 400 亿 tokens（F81）；API 激进定价（F46/F57）抢份额；与荣耀等厂商深度合作（F34 备注）；2025-04 首家启动 IPO（F38）并 2026 年港股上市（F80），资本化走在国产大模型前列。

## 3.4 智谱模型策略判断

**事实**：官方披露的迭代重心依次为「对话基座（2023）→ 对标 GPT-4（2024）→ 推理与 Agent（2025）→ Coding 与长程任务（2026）」；开源旗舰与闭源 API 双轨并行（F47 vs F19）；国产算力适配从「适配」升级为「训练底座」（F54/F70/F79）。

**推断**：
1. 智谱更重视「高参数效率 + Agent 落地」——GLM-4.5 以 355B/32B 实现 12 基准全球第三（F43），GLM-5.2 以约 753B/40B 冲击 AA 前三（F73–F74），走的是「小激活、深架构、强后训练」路线而非单纯堆参数量。
2. 开源/闭源分工：开源负责影响力、生态与开发者信任，闭源负责商业变现与高端服务；当前主流旗舰全部开源，说明智谱判断「开源即最强营销」的阶段仍未结束。
3. 相对位置：与 DeepSeek 拼价格与推理、与 Kimi 拼 Agentic Coding 相比（F40/F69），智谱的差异化是「开源旗舰 + 国产算力全栈自研」，是国产大模型「六小虎」中资本化与全栈能力最均衡的玩家之一。
4. **当前资料不足以支持**：GLM-5/5.1/5.2 的总参数量（官方未披露，F65/F68/F73）、GLM-5.2 API 单价、GLM-4.6 之后的详细参数与训练数据规模、以及 GLM-4.7 之后智谱的下一代闭源旗舰规划——均需官方后续披露。
