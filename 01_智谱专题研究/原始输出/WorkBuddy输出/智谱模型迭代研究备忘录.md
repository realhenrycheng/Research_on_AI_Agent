# 智谱模型迭代研究备忘录

## 3.1 核心结论

1. **迭代路径清晰且加速**：GLM 架构（2021）→ GLM-130B（2022）→ ChatGLM-6B 开源引爆（2023-03）→ GLM-4（2024-01，128K+All Tools）→ GLM-4.5（2025-07，ARC 原生融合）→ GLM-4.7（2025-12，200K+编码 SOTA）→ GLM-5.2（2026-06，1M+长程任务）。（见 F01–F13）
2. **开源与闭源双轨分工**：ChatGLM 系列及 GLM-4-9B/4.5/4.5V/4.7/5.2 均权重开源（MIT 等），GLM-4、GLM-4-Plus 闭源走 API/产品，形成「开源引流+闭源变现」互补。（F34–F37）
3. **能力重心明确转向 Agent**：GLM-4.5 首次在单一模型原生融合推理/编码/智能体（ARC），GLM-4.7 引入三种思考模式，GLM-5.2 主攻长程任务与 Coding。（F51–F55）
4. **上下文长度阶梯跃升**：GLM-4 的 128K → GLM-4.7 的 200K → GLM-5.2 的 1M 无损，直接服务长文档、整库代码与长程自主任务。（F23、F27、F28）
5. **多模态从「理解」走向「生成+行动」**：GLM-4V 图像理解 → CogView3/CogVideoX 文生图/视频 → GLM-4-Voice 语音 → AutoGLM 端侧操作手机/PC。（F30–F33、F54）
6. **性价比与国产算力是差异化卖点**：GLM-4-Flash 免费、GLM-4-Air 0.5 元/百万 tokens；GLM-5.2 Day 0 适配昇腾等 9 家国产芯片。（F47、F49、F55）
7. **当前相对位置**：GLM-5.2 在 Artificial Analysis 综合 51 分，列开源 SOTA、全球前三（与 Anthropic/OpenAI 并称「新御三家」），Code Arena 全球可用模型第一。（F44、F45）

## 3.2 模型迭代时间线

- **2021–2022 基础研究期**：提出 GLM 自回归空白填充架构，训练 GLM-10B；2022-09 开源中英双语 130B 稠密模型 GLM-130B，入选斯坦福全球大模型评测。
- **2023 开源引爆期**：2023-03-14 开源 ChatGLM-6B（6.2B），成为国内现象级开源对话模型，开启本地部署时代；6 月 ChatGLM2-6B 扩至 32K，10 月 ChatGLM3-6B 支持 Function Calling，Agent 能力雏形出现。
- **2024 闭源主力+多模态扩张期**：2024-01 GLM-4 发布（128K、All Tools、逼近 GPT-4）；6 月开源 GLM-4-9B 与 GLM-4V-9B；7 月 CogVideoX 文生视频；8 月 GLM-4-Plus；10 月 GLM-4-Voice 与 AutoGLM；12 月 GLM-Zero-Preview。
- **2025 Agent 原生期**：2025-04 开源 GLM-4-32B/GLM-Z1 系列并启用 z.ai；7 月 GLM-4.5（MoE 355B/32B）原生融合 ARC；8 月 GLM-4.5V 视觉推理开源；9 月 GLM-4.6、12 月 GLM-4.7（200K、编码开源 SOTA）。
- **2026 长程任务期**：GLM-5/5.1 过渡（细节未披露），2026-06-17 GLM-5.2 上线，1M 无损上下文、长程任务稳定执行、国产算力全适配，标志主攻「自动驾驶级」数字生产力。

## 3.3 能力演进分析

- **文本理解与生成**：从 GLM-130B 的基座，到 GLM-4 中文比肩 GPT-4（MMLU 81.5≈GPT-4 94%），到 GLM-4.5/4.7 在推理与综合基准持续逼近闭源 SOTA，文本能力已非短板。
- **长上下文**：128K（GLM-4）→ 1M（GLM-4-9B-Chat-1M 与 GLM-5.2）的跨越，使整库代码、数百页 PDF、长篇巨著可一轮处理，是 Agent 与长程任务的基础。
- **多模态**：理解侧（GLM-4V/4.5V）已达开源 SOTA；生成侧（CogView3 文生图、CogVideoX 文生视频）与交互侧（GLM-4-Voice、GLM-4Videocall）齐全，形成「全模态」产品矩阵。
- **工具/API 与 Agent 化**：GLM-4 的 All Tools → GLM-4.5 原生 Function Call+MCP+混合推理 → GLM-4.7 三种思考模式 → GLM-5.2 effort level 与 IndexShare，Agent 能力从「能调用」走向「能长程自主执行」。
- **开源生态**：ChatGLM-6B 累计千万级下载、智谱开源系列超 3000 万下载/15 万 GitHub 星标，开源是智谱建立开发者心智与生态壁垒的核心抓手。
- **企业级与商业化**：MaaS 模式（bigmodel.cn 客户超 50 万）、API/云端私有化/本地私有化三档，叠加免费模型引流，2025 年提交 IPO、2026 年港股上市（02513.HK），商业化路径清晰。

## 3.4 智谱模型策略判断

**事实（可核验）**：
- 开源模型覆盖 6B→9B→32B→106B→355B 多档，且 GLM-4.5/4.7/5.2 旗舰同步开源（MIT）。（F36、F37）
- GLM-4.5 起明确以「Agentic、Reasoning、Coding（ARC）」为统一训练目标，技术报告公开训练与 RL 框架 slime。（F51，arXiv:2508.06471）
- GLM-5.2 价格未在检索来源中披露，但强调国产算力适配与 MIT 免费商用。（F55、F22）

**推断（需持续验证）**：
- 智谱更重视「Agent 原生 + 长上下文 + 高性价比开源」三条主线，意在以开源生态对抗闭源巨头、以国产算力规避供应链风险。
- 开源与闭源分工：开源建立开发者生态与口碑（对标 Meta Llama 路线），闭源 API（GLM-4/4-Plus）及企业私有化承接付费，二者流量与收入互补。
- 相对位置：国产开源模型第一梯队，与 DeepSeek、Qwen 并称；在编码/长程任务上正快速逼近 Claude/OpenAI，但总参数与部分基准仍落后顶级闭源。
- **当前资料不足以支持**：①GLM-4.6/5/5.1 的参数、具体发布日与能力细节；②GLM-5.2 的 API 单价与训练算力规模；③各版本真实训练成本与利润率。上述均列为「未确认信息」。
