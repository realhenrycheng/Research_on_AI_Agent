# 3. 研究备忘录

## 3.1 核心结论

- 智谱的主线不是单一模型参数扩张，而是从 GLM 架构验证、ChatGLM 对话开源、GLM-4 闭源旗舰/API、GLM-4.5 MoE 开源旗舰逐步转向“模型即服务 + 开源生态”并行，依据见 F001-F003、F023-F025、F048-F053。
- 早期 ChatGLM 系列的主要价值在于低门槛本地部署和中文对话生态，ChatGLM-6B 的 6.2B 参数、INT4 量化与开放许可构成了第一阶段扩散基础，依据见 F006-F010。
- ChatGLM2/3 的迭代重点是长上下文、推理效率、工具调用和 Agent 任务，ChatGLM2 把上下文扩至 32K，ChatGLM3 引入 Function Call、Code Interpreter 和 Agent 任务，依据见 F013-F022。
- GLM-4 是能力中枢升级：128K 长上下文、All Tools、中文对齐和 API 产品化同步推进，但总参数量仍未披露，依据见 F023-F029。
- 2024 年中后期，智谱把 GLM-4 能力拆成高性能、低价、免费、多模态和开源 9B 版本，说明其策略从“单旗舰”转为“场景分层”，依据见 F030-F044。
- 2025 年 GLM-4.5 把策略重点转向 ARC：Agentic、Reasoning、Coding，并以 MIT License 开源 355B-A32B 与 106B-A12B 两档模型，依据见 F048-F054。
- 多模态线从 VisualGLM-6B、GLM-4V、GLM-4V-Plus 发展到 GLM-4.5V，能力从图像问答扩展到视频、GUI、文档和视觉推理，依据见 F011、F034、F038-F041、F055-F059。

## 3.2 模型迭代时间线

2021-2022 年，GLM 架构和 GLM-130B 解决的是“能否训练并开放百亿到千亿级双语模型”的问题，核心成果是 130B 双语预训练、训练稳定性、INT4 量化和开源验证。2023 年 3 月，ChatGLM-130B 上线，ChatGLM-6B 开源，智谱进入对话产品和开发者生态阶段。2023 年 6 月到 10 月，ChatGLM2/3 把重点转向 32K/128K 上下文、推理效率、函数调用、代码解释器和 Agent 任务。

2024 年 1 月，GLM-4 和 GLM-4 All Tools 把长上下文、工具自主选择和网页/代码/图像工具纳入旗舰能力。2024 年 6 月，GLM-4-9B、GLM-4V-9B 把旗舰能力开源到 9B 级模型。2024 年 9 月，GLM-4-Plus、GLM-4V-Plus、GLM-4-Flash 形成高性能、多模态和免费 API 的产品分层。2025 年 4 月到 8 月，GLM-4-0414、GLM-4.5、GLM-4.5V 进一步转向推理、代码、Agent 和视觉推理。

## 3.3 能力演进分析

文本理解与生成方面，ChatGLM-6B 先解决双语对话可用性，ChatGLM2/3 通过更多数据和训练策略提升 MMLU、C-Eval、GSM8K、BBH 等指标，GLM-4 与 GLM-4-Plus 则以高性能 API 承接复杂任务。长上下文方面，路径清晰地从 2K 到 32K、128K，再到 GLM-4-9B-Chat-1M 的实验性 1M 上下文和 GLM-4.5 的 128K 上下文。

多模态方面，智谱先用 VisualGLM-6B 与 GLM-4V 建立图像理解，再用 GLM-4V-Plus 扩展到视频时间问答和长视频，最终用 GLM-4.5V 将 GUI、文档、视频和视觉推理纳入统一模型。工具/API 与 Agent 化能力方面，ChatGLM3 是开源端起点，GLM-4 All Tools 是闭源产品化样板，GLM-4.5 则把工具使用、推理和代码合并为 ARC 目标。

开源生态方面，智谱持续用 6B、9B、32B、355B-A32B、106B-A12B 不同规模模型覆盖研究、轻量部署和高性能开源场景。企业级和商业化方面，GLM-4-Plus、GLM-4V-Plus、GLM-4-Flash 与 GLM-4.5 API 形成价格和能力分层，免费 API 与 MIT 开源降低开发者试用门槛。

## 3.4 智谱模型策略判断

事实层面，智谱持续投入中文/英文文本、长上下文、工具调用、代码、Agent、多模态和开源生态；GLM-4.5 技术报告把 Agentic、Reasoning、Coding 明确为核心能力。推断层面，智谱更重视“可完成复杂任务”的模型，而不是只追求聊天质量；其闭源/API 产品承担稳定商业服务和快速迭代，开源模型承担开发者扩散、研究复现和生态建设。

在国内竞争格局中，智谱的相对位置可描述为“开源与 API 同时押注、Agent 能力表达较强、中文生态较早积累”。但资料不足以支持精确判断其真实用户规模、企业收入、训练成本、推理利润率、闭源旗舰参数规模，以及所有第三方 Benchmark 的独立复现程度。
