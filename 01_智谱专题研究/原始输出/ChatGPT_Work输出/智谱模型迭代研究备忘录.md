## 3.1 核心结论

- 智谱模型迭代可分为四段：GLM 预训练范式与 GLM-130B 千亿基座验证（F01-F07）、ChatGLM 开源对话生态（F08-F28）、GLM-4 多模态/API 产品化（F29-F36）、GLM-4.5 以后面向推理、代码与 Agent 的旗舰路线（F37-F55）。
- ChatGLM-6B 到 ChatGLM3 的核心价值不是追求最大参数，而是降低本地部署门槛、提升中文对话、长上下文、工具调用和 Agent 原型能力（F11-F28）。
- GLM-4 起，智谱形成“闭源/API 旗舰 + 开源小/中模型 + 产品入口”的组合：GLM-4 面向清言和 API，GLM-4-9B/32B 面向开源开发者，GLM-4V/Plus/Flash 承接视觉与视频理解（F29-F36）。
- GLM-4.5 是策略拐点：官方明确披露 MoE 参数、128K 上下文、Thinking/Non-thinking、工具调用和开源权重，说明智谱将重点从通用聊天转向 Agent 应用（F37-F41）。
- GLM-4.6、4.7、5、5.2 连续强化代码、工具使用、长程任务和工程代理；上下文从 128K 到 200K，再到 GLM-5.2 的 1M，显示“长周期可执行任务”成为主轴（F42-F55）。
- 竞争判断需谨慎：官方博客多次对比 Claude、GPT、DeepSeek、Kimi、Qwen，但多数为官方评测或自建任务，研究中可用于判断方向，不能单独作为市场排名结论（F44、F46、F54）。

## 3.2 模型迭代时间线

2021-2022 年，GLM 先解决预训练范式问题：用自回归填空统一理解与生成任务，并通过 GLM-130B 验证千亿双语模型与量化部署能力。2023 年，ChatGLM 将模型能力产品化和开源化：ChatGLM 是千亿对话基座，ChatGLM-6B 则用 6.2B 参数和 INT4 低显存部署建立开发者入口。随后 VisualGLM-6B 补上图像理解，ChatGLM2 把上下文扩到 32K、提升推理效率，CodeGeeX2 把路线延伸到代码，ChatGLM3 进一步加入 Function Call、Code Interpreter 和 Agent 任务。

2024 年，GLM-4 标志旗舰模型迭代。官方产品侧强调 Function Call、结构化输出、联网/检索和 MCP；开源侧发布 GLM-4-9B、GLM-4V-9B 等，使旗舰能力下沉到本地部署。GLM-4V-Plus/Flash 则把视觉理解扩到图像、视频、视觉定位和免费图像理解 API。

2025-2026 年，GLM-4.5 以后路线明显 Agent 化。GLM-4.5 用 MoE、128K、96K 输出和混合思考模式统一推理、代码、Agent；GLM-4.6 将上下文扩到 200K；GLM-4.7 强化多语言代码、terminal 任务和跨轮思考；GLM-5 把定位升级为 Agentic Engineering；GLM-5.2 则把 1M 上下文、IndexShare 和长周期 coding-agent 评测作为核心卖点。

## 3.3 能力演进分析

文本理解与生成：GLM 阶段关注统一预训练目标，ChatGLM 阶段关注中文对话和人类偏好对齐，GLM-4 以后逐步增强结构化输出、复杂指令遵循和写作可读性。

长上下文：ChatGLM2 从 2K 扩到 32K，ChatGLM3 提供 8K/32K/128K，GLM-4-9B 开源序列出现 128K 与 1M 变体，GLM-4.6 到 200K，GLM-5.2 把重点放到稳定 1M 上下文与长周期任务。

多模态：VisualGLM-6B 是早期图像理解探索；GLM-4V-9B、GLM-4V-Plus 和 GLM-4V-Flash 形成开源、付费 API、免费视觉 API 的多层布局，并扩展到视频理解。

工具/API 与 Agent 化能力：ChatGLM3 已原生支持 Function Call、Code Interpreter 和 Agent；GLM-4 产品文档增加 MCP、结构化输出、上下文缓存；GLM-4.5 以后把工具调用、网页浏览、代码代理框架兼容写入核心定位。

开源生态：早期 ChatGLM 侧重小参数低门槛，GLM-4 开源 9B/32B，GLM-4.5 以后连旗舰模型也以开放权重参与生态竞争，GLM-5.2 进一步强调 MIT 许可证。

企业级和商业化能力：API 平台、OpenAI SDK 兼容、上下文缓存、结构化输出、模型套餐和 Coding Plan 说明智谱不只卖模型，也在经营开发者工作流与企业集成入口。

## 3.4 智谱模型策略判断

事实层面：智谱持续投入语言、长上下文、多模态、代码、工具调用和 Agent；2025 年后官方发布频率明显围绕 reasoning/coding/agentic tasks 展开；开源权重、API、网页产品和 coding agent 集成同时出现。

推断层面：智谱的模型策略正在从“中文对话与开源普及”转向“开源旗舰 + Agent 工程场景”。开源模型用于扩大开发者采用、获得框架适配与社区反馈；闭源/API 和 Coding Plan 用于商业化、稳定服务和企业集成。与国内大模型竞争格局相比，智谱的相对位置更偏“开源可用 + Agent/coding 工程化”，与 DeepSeek、Qwen、Kimi 等在代码、推理、长上下文和成本上正面竞争。

资料不足以支持的判断包括：GLM-4 首发完整参数、GLM-4/4V 首发精确 benchmark、GLM-5 的准确发布日期、各模型真实线上调用量、商业收入贡献、企业客户结构，以及官方评测是否能完全代表第三方真实使用效果。
