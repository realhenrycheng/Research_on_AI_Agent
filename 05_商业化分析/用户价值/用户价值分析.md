## 二、逐类分析

### 1. 个人知识工作者
- **价值场景**：资料检索（R2 实证）、文档写回修订（R1 实证）、晨报/监控（测试一能力）；
- **负价值场景**：PPT 制作+邮件分发（R3 失败，60 分钟 vs 人工 10-20 分钟）；
- **成本测算**：正常办公月耗 1,000-2,000 积分 ≈ ¥50-100，标准版 ¥70/月（4,000 积分）刚好覆盖；
- **结论**：对"以检索和文档为主"的个人用户成立；对"需要对外交付成品"的用户不成立。

### 2. 技术型研究员
- 与 H3 假设一致：有编程能力者可用 Python/脚本替代部分功能（本项目 04 实验本身就用 python-pptx、pdfkit 兜底）；
- WorkBuddy 的增量价值主要在"免写代码的 agent 调度"，而非模型能力本身；
- 结论：增量价值有限，但可作为"低代码 agent 平台"吸引此群体中的非硬核用户。

### 3. 非技术型研究员
- **本项目最适配的群体**：低门槛 + 带复核闭环的工作流；
- 证据：MuDABench 口径分歧全部被"不确定性表达"充分暴露，说明 agent 知道何时需要人确认——这对非技术用户反而安全；
- 风险：需人工复核（04 实测 4 次干预），非技术用户可能不擅长判断何时复核；
- 结论：价值明显但需要"复核点机制化"降低使用负担。

### 4. 中小团队
- 核心卖点：知识库共享（R2 实证）+ 团队积分池 + 项目/成员管理 + SSO；
- 企业版 ¥198/人/月 ≈ 飞书 AI 灵活档（¥69/人/月）的 3 倍，但功能覆盖更全（agent 执行+知识库+文档）；
- 结论：对 5-20 人研究型/内容型团队价值成立，前提是稳定性问题被解决（04 实测）。

### 5. 大型企业
- 核心卖点：专有云数据不出域、租户隔离、安全审计、SSO——对应 04 实测的"企微入口企业专属"；
- 个人用户够不到的入口层（企微）恰恰是企业标配，说明 **WorkBuddy 生态深度与企业用户需求高度匹配**；
- 风险：稳定性（04 实测通道崩溃/依赖装不上）在企业级 SLA 下不可接受；
- 结论：价值主张最成立，但交付稳定性是最大门槛。

## 三、用户分层商业含义

1. **个人市场**：靠"检索+知识库"场景转化（标准/高级版），但 R3 类失败体验会流失用户；
2. **企业市场**：靠"生态+安全+管理"转化（企业版），但稳定性不达标前难规模化；
3. **优先级建议**：先做"研究/内容型个人用户+中小团队"，稳定后再攻大型企业——与"草房子先装修能住，再谈办公楼"的结论一致。
