# 决策记录

## 2026-08-04

- 整个项目是 WorkBuddy 产品、生态、竞品与商业化专题研究；“实测”只是其中的证据模块。
- 核心问题：WorkBuddy 是否具备成为知识工作者，尤其是行业研究员核心工作入口的潜力。
- 测试一采用智谱模型迭代真实研究任务。
- 测试二采用 Factcheck-GPT / FactBench 和 FACTS Grounding。
- 测试三采用 SpreadsheetBench 2 和 DECKBench。
- 三个平台为 WorkBuddy、ChatGPT Work、TRAE Work。
- 人工流程作为效率和质量基线，不作为第四个竞品。
- 随机种子统一为 20260804。
- 提示词、样本、材料和评分规则必须在正式运行前冻结。
- Codex 不纳入核心实测，因为更接近 CodeBuddy 的软件开发 Agent 类别。
- Manus 不纳入核心实测。
- 标准化 Benchmark 不要求围绕智谱主题；它们用于提高评分可信度和可复现性。
- 测试一是开放研究任务，需要人工复核，但必须采用预先冻结的事实清单、引用核验和 Rubric，而不是凭印象打分。
