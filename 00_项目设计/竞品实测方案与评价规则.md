# 竞品实测方案与评价规则

## 适用范围

本文件只服务于 WorkBuddy 专题项目中的“竞品实测”模块，不把整个专题项目称为实验。整个项目仍然是 WorkBuddy 产品、生态、竞品与商业化专题研究。

## 已冻结基本设定

- 核心研究对象：WorkBuddy。
- 对照竞品：ChatGPT Work、TRAE Work。
- 人工流程：作为质量与效率基线，不作为第四个竞品。
- 随机种子：20260804。
- 测试一：以“智谱模型迭代研究”为真实开放式行业研究任务。
- 测试二：使用 Factcheck-GPT / FactBench 和 FACTS Grounding 作为标准化事实核验测试。
- 测试三：使用 SpreadsheetBench 2 和 DECKBench 作为标准化办公成果编辑测试。
- Codex 不纳入核心实测，因为它更接近 CodeBuddy 一类的软件开发 Agent。
- Manus 不纳入核心实测。
- 标准化 Benchmark 不要求围绕智谱主题；它们的作用是提供可复现、可评分的能力证据。

## 三项核心测试

1. 专题研究生成测试：考察 Agent 能否从零完成一项真实行业研究，并形成可交付成果。
2. 事实核验与材料 grounding 测试：考察 Agent 能否识别事实错误、引用证据，并避免无依据推断。
3. 办公成果编辑测试：考察 Agent 能否维护既有 Excel 和幻灯片资产，而不是只生成文字。

## 人工干预规则

| 等级 | 行为 | 记录方式 |
|---|---|---|
| L0 | 权限确认、文件上传、选择保存目录 | 只记录，不计能力性干预 |
| L1 | 要求 Agent 继续执行已经明确的任务 | 计 1 次轻度干预 |
| L2 | 重新解释已有要求，或提醒遗漏交付物 | 计 1 次中度干预 |
| L3 | 提供新事实、修正方法，或人工代替 Agent 修改文件 | 计 1 次重度干预 |

每个正式任务最多允许 3 次能力性干预。超过后标记为“未自主完成”，但可以继续执行以收集后续分析材料。
