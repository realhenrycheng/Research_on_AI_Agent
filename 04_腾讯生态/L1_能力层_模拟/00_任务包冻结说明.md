# 腾讯办公生态场景模拟测试：L1 能力层任务包冻结说明

冻结版本：V1.1（2026-08-06，目录按 L 级重构后更新路径，内容未变）

## 固定对象

- 核心 agent：WorkBuddy；
- 对比配置：HY3 与 DeepSeek V4 Flash；
- 运行模式：仅手动指定模型，不使用 Auto；
- Skill：两组使用同一版本，运行记录中填写 Skill 名称和版本；
- MAX：主实验手动关闭。若单独观察 MAX，必须另建“扩展观察组”，不得混入主评分；
- 输入文件：仅使用本层 `01_资料包` 下冻结文件，按“文件顺序.txt”上传；
- 输出格式：必须严格使用各任务的固定提示词，并生成指定路径下的 Markdown 文件；
- 评分：仅以本层 `02_评分锚点` 目录中的答案评分，评分锚点不向被测模型展示。

## 任务包构成

### HERB-01：项目审阅报告

- 输入：`01_资料包\HERB_ProposalForce\第一阶段` 下的文件；
- 输出：`04_任务输出\{模型名称}\HERB+{模型}\HERB-01_ProposalForce项目审阅与推进报告.md`；
- 评分：关键事实、来源可复核性、材料不足拒答、结构化交付；
- 隐藏评分：`02_评分锚点\HERB_01_评分锚点.json`。

### HERB-02：追加材料后的修订

- 前置：完成 HERB-01；
- 输入：HERB-01 原始文件加 `01_资料包\HERB_ProposalForce\第二阶段追加材料`；
- 输出：修订后的报告与“本次变更说明”；
- 评分：新增事实、旧结论更新、无关信息保留、变更可追溯；
- 隐藏评分：`02_评分锚点\HERB_02_评分锚点.json`。

### MUDA-01 至 MUDA-06：中文企业资料库分析

- 输入：`01_资料包\MuDABench_中文企业资料库分析` 每题目录下的题目说明和关联 PDF；
- 输出：最终结论、支撑事实与计算过程、来源文件及证据、不确定项或人工确认项；
- 评分：`02_评分锚点\MuDABench_6题评分锚点.json`；
- 禁止：上传与该题无关的 PDF，或在材料外补充事实。

## 固定记录项

每次运行必须在操作记录中填写：任务编号、模型、MAX 状态、Skill、开始和结束时间、积分或 API 成本、输出路径、文件解析失败情况、人工复核发现的问题数量。

所有测试文件仅可写入 `F:\GitHub\AI_Agent\04_腾讯生态\L1_能力层_模拟\04_任务输出\{模型名称}\`。`{模型名称}` 仅可取 `HY3` 或 `DeepSeek_V4_Flash`；不同任务使用不同文件名，禁止覆盖已有输出。

## 变更管理

- 任何对本冻结说明的修改（提示词、任务包、输出路径、输出格式、评分标准）必须先升版本号并在文末追加变更记录；
- 未变更上述任何一项时，才允许将两组结果做横向比较；如发生变化，必须另记为非主实验结果。
