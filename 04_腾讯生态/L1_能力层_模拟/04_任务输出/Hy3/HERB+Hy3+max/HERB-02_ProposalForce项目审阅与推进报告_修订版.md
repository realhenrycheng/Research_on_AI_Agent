- **产品定位**：ProposalForce 是一款销售自动化 / 提案生成工具，覆盖市场研究、产品愿景、实时协作、身份认证安全、移动端体验等方向。（来源：20261219-0-ff6ae、20261226-0-cfc80、product_dev_ProposalForce_1）

- **产品方向两次转变（阶段二新增，关键）**：

  2. **2027-04-22**：焦点进一步转向"**差异化的独立移动端体验**，而非让移动端镜像桌面端"。（来源：20270421-2-5d6bf、20270421-3-434a1）
- **PR 总览（合并状态以 GitHub 元数据为准）**：
  - 已合并：JWT 会话管理（PR#5）、MFA 多因素认证（PR#13，GitHub `merged=True`；见第 3、4 节矛盾说明）。
