按样本标准差口径（分母 n-1），仅以有"营业总成本"科目的 2 家公司计算：

| 年度   | 样本数 n | 营业总成本样本标准差                  | 单位   |

### 2.2 样本标准差计算（样本标准差 = √[ Σ(xᵢ − x̄)² / (n−1) ]，n=2 时分母为 1）

- 样本标准差 = |2,327,149,068.86 − 964,551,921.05| / √2 = **963,501,683.24 元**

**2022 年度：**

- 样本 x₁ = 1,494,888,659.26，x₂ = 661,377,049.76
- 均值 x̄ = (1,494,888,659.26 + 661,377,049.76) / 2 = 1,078,132,854.51
- 样本方差 = [(416,755,804.75)² + (−416,755,804.75)²] / (2−1)
- 样本标准差 = |1,494,888,659.26 − 661,377,049.76| / √2 = **589,381,711.28 元**

### 2.3 变化量

Δ标准差 = 589,381,711.28 − 963,501,683.24 = **−374,119,971.97 元（约 −3.741 亿元，降幅 −38.83%）**

## 四、不确定项或人工确认项

1. **样本范围口径**：本结论仅纳入资料中明确披露"营业总成本"科目的 2 家非银企业（n=2/年）。8 家银行年报全文无"营业总成本"科目，未纳入。**若任务口径预期覆盖全部 10 家公司（例如将银行"营业支出"科目近似视作"营业总成本"），需要人工确认该口径映射是否成立**；若成立，需补充 8 家银行 2021/2022 年"营业支出"数据后重新计算，结果将与本结论不同。
2. **数据单位**：所有数值为各公司合并利润表披露的人民币元（风语筑、宋城演艺）；银行附注数据以百万元计，未纳入计算。
3. **样本量极小（n=2）**：样本标准差在 n=2 时分母为 1，统计意义有限；该结果仅反映本知识库资料范围内可提取数据的离散度变化，不代表市场总体。
4. 资料中未发现其他公司或渠道提供的"营业总成本"数据，未使用任何外部数据或常识补全。
