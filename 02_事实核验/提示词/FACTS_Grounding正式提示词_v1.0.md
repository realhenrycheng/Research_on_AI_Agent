# FACTS Grounding 正式提示词 v1.0

## 冻结信息

- 适用测试：测试二“事实核验”中的 FACTS Grounding 子任务。
- 版本：v1.0。
- 冻结日期：2026-08-04。
- 输出语言：中文；来自材料的英文原文引句必须保留原文。
- 适用对象：WorkBuddy、ChatGPT Work、TRAE Work。

## 本题材料与唯一证据边界

请只阅读本题任务包中的 `任务说明.md` 和 `context_document.md`。

`context_document.md` 是**唯一允许使用的事实来源**。不得联网，不得搜索，不得读取同目录之外的资料，不得使用模型既有知识补充材料未出现的内容，也不得访问 FACTS Grounding 原始数据中的评价提示或标准答案。

任务说明会给出用户请求。请基于 `context_document.md` 完成该请求，并让每一项关键结论能回指到原文。

## 工作要求

1. 先阅读用户请求，识别其要求的回答形式，例如直接问答、列表、比较、总结或逐项归纳。
2. 只从 `context_document.md` 提取信息。若材料未提供回答所需信息，明确写：`根据提供材料无法判断。`
3. 不得将材料中的推测、观点或条件性表述改写为确定事实；应保留“可能”“通常”“在……条件下”等限定。
4. 不得拼接来自不同段落、但原文没有建立因果关系的信息，形成新的因果结论。
5. 每个关键结论都要提供 1 个最短且充分的英文原文引句，并给出段落编号。引句只能来自 `context_document.md`。
6. 回答应简洁、直接完成用户请求；证据映射用于复核，不要用冗长转述掩盖证据不足。

## 交付要求

本题输出绝对路径必须使用以下模板，并在开始前将花括号替换为实际值：

```text
F:\GitHub\AI_Agent\02_事实核验\原始输出\{平台输出目录}\{测试编号}
```

`{平台输出目录}` 只能填写以下之一：`ChatGPT_Work输出`、`WorkBuddy输出`、`TRAE_Work输出`。`{测试编号}` 必须与 `任务说明.md` 一致，例如 `FACTS_001`。

示例：ChatGPT Work 执行 `FACTS_001` 时，输出路径为：

```text
F:\GitHub\AI_Agent\02_事实核验\原始输出\ChatGPT_Work输出\FACTS_001
```

请先创建该测试编号目录，再在其中创建以下两个文件：

1. `grounding回答.md`
2. `grounding证据映射.csv`

除上述两个文件外，不要求创建其他文件。

不得写入其他目录，不得省略测试编号子目录，不得使用临时目录替代正式输出目录。若平台无权写入该路径，必须明确报告“无法写入指定输出路径”，不得改用其他路径。

### `grounding回答.md` 固定结构

```markdown
# Grounding 回答

## 1. 任务信息

| 项目 | 内容 |
| --- | --- |
| 测试编号 | {{测试编号}} |
| 上下文分层 | 短上下文 / 中等上下文 / 长上下文 |
| 联网状态 | 禁止联网 |

## 2. 对用户请求的回答

直接回答用户请求。若请求要求项目符号、比较或逐项总结，应严格遵守其格式。

## 3. 证据映射

| 编号 | 回答中的关键结论 | 段落编号 | 英文原文引句 | 判断 |
| --- | --- | --- | --- | --- |
| G01 | ... | P03 | "..." | 已由材料支持 / 根据提供材料无法判断 |

## 4. 材料边界说明

只列出确实无法根据材料回答的部分；没有则写“无”。
```

### `grounding证据映射.csv` 固定列

```text
测试编号,编号,关键结论,段落编号,英文原文引句,判断,材料边界说明
```

`判断`只能填写：`已由材料支持` 或 `根据提供材料无法判断`。若为后者，段落编号和英文原文引句填写“无”。

## 禁止事项

- 禁止联网、调用搜索工具、引用外部链接或外部知识。
- 禁止访问 `evaluation_prompts.csv`、`examples.csv` 中本题以外的内容，或任何标签、评分、参考答案字段。
- 禁止在材料未明确说明时给出精确数字、因果关系、人物身份、时间或价值判断。

## 完成标准

- 回答与用户请求相对应，关键结论均可从材料原文追溯。
- 证据映射中的引句能直接支持结论，而不只是主题相关。
- 任何材料外补充都视为违规；宁可明确材料不足，也不要补充常识。
