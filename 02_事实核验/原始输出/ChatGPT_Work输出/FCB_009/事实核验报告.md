## 4. 修正版

ECharts Java is a Java-based library for data visualization. It provides an easy-to-use interface for creating charts, graphs, and other visual elements to represent data. ECharts Java is based on Apache ECharts, an open-source JavaScript visualization library. Using ECharts Java, developers can create interactive and customizable charts and graphs to display data in a more visually appealing way. It supports a wide range of chart types including line charts, bar charts, pie charts and more.

## 5. 复核风险

“widely used in web applications”属于采用范围判断，需更多权威使用量或采用案例证据；本次未将其判为事实成立。
